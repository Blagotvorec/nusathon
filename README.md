# NUSATHON — второй сайт цепочки

Статический сайт: две страницы, один стиль, один скрипт. Ни сборки, ни
зависимостей — nginx отдаёт эту папку как есть, `npm run build` её не
касается.

```
nusathon/
  index.html        платформа — герой, программа, издания, журнал, цепочка
  apply.html        заявка на участие
  assets/style.css  весь визуальный язык
  assets/app.js     смена слова в логотипе и отправка формы
  robots.txt        и sitemap.xml
  DEPLOY.md         как поднять на сервере
```

Посмотреть локально — из корня репозитория:

```bash
python3 -m http.server 5174 --directory nusathon
```

## Что осталось заполнить

1. **Полоса анонса** в `index.html` (дата, город, открыт ли приём заявок).
   Это единственное, что возвращающийся посетитель проверяет, поэтому
   устаревшая дата стоит здесь дороже, чем где-либо ещё на сайте.

2. **Записи в журнале.** Четыре штуки в `index.html` — заглушки: они
   показывают форму ленты и ни о чём не сообщают (дата у всех «Coming
   soon»). Заменить настоящими постами или убрать секцию.

3. **Куда идут заявки.** В `assets/app.js` вверху стоит `APPLY_ENDPOINT =
   null` — форма открывает почтовый клиент посетителя с уже заполненным
   письмом на `info@buildinclt.com`. Это работает без сервера. Чтобы
   собирать заявки на сервере, впиши туда путь до эндпоинта, принимающего
   JSON, — у INCLT для этого уже есть `/api/waitlist`.

## Домены

`nusathon.com` — основной. `modulthon.com` — 301 на него: издания живут
внутри платформы, отдельным сайтом Modulthon не будет. Оба заведены в
GoDaddy 8 сентября 2026.

## Дизайн

Костяная бумага, тёплый чёрный, тот же древесный тан из палитры INCLT и та
же пара шрифтов — INCLT это тёмный интерьер, этот сайт его дневной близнец.
Держат всё ограничения: волосяные линейки, никаких заливок и теней, а поля
формы — подчёркивание, а не рамка.
