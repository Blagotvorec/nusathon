# NUSATHON — портал

Статический сайт: русская версия основная, английская лежит в `/en/`. Ни
сборки, ни зависимостей — nginx отдаёт папку как есть, `npm run build` её не
касается.

```
nusathon/
  index.html          портал (RU) — миссия, материал, галерея, хакатоны, лента
  apply.html          заявка (RU)
  en/index.html       то же по-английски
  en/apply.html
  assets/style.css    вся тема; цвета вынесены в токены в первом блоке
  assets/app.js       смена слова в заголовке EN и отправка формы
  assets/logo.svg     знак
  assets/logo-lockup.svg  знак со шрифтовой частью
  robots.txt sitemap.xml
  DEPLOY.md           как поднять на сервере
```

Посмотреть локально — из корня репозитория:

```bash
python3 -m http.server 5174 --directory nusathon
```

## Знак

Два слоя досок, положенных поперёк друг друга, через одну сверху и снизу. Это
буквально устройство CLT-панели — и одновременно anyaman, плетение
индонезийского ремесла. Ничего не нужно переводить и не с чем связывать эпоху.

Файл раскрашивается не сам: в шапке он подставлен CSS-маской
(`.mark__glyph`), поэтому берёт цвет текста и работает на любом фоне. Внутри
`logo.svg` стоит `fill="currentColor"` и тёмный цвет по умолчанию — он виден,
если открыть файл отдельно.

## Тема

Чёрная. Все цвета — восемь значений в `:root` в начале `assets/style.css`;
инвертировать тему целиком значит поменять их, а не искать цвета по файлу.
Древесная краска `--wood` та же, что у INCLT, — сайты читаются как один дом.

## Что осталось заполнить

1. **Фотографии.** В секции «Вдохновение» шесть слотов; каждый подписан, какой
   кадр в него нужен. Кладём файлы в `nusathon/photo/` и заменяем
   `<div class="shot__slot">…</div>` на `<img src="./photo/имя.jpg" alt="…">`.

2. **Полоса анонса** в `index.html` — дата, город, открыт ли приём заявок.

3. **Записи в ленте.** Четыре штуки — заглушки с датой «Скоро»: они показывают
   форму ленты и ни о чём не сообщают. Заменить настоящими или убрать секцию.

4. **Куда идут заявки.** В `assets/app.js` вверху `APPLY_ENDPOINT = null` —
   форма открывает почтовый клиент с готовым письмом. Чтобы собирать заявки на
   сервере, впиши путь до эндпоинта, принимающего JSON.

## Про цифры на странице

Раздел «Материал» опирается на исследования, и там же стоит оговорка: готовая
панель **не** поглощает CO₂ из воздуха — углерод забирает живое дерево, а
панель его хранит. Числа «сколько хранится» и «сколько не выброшено взамен
бетона» разные, и путать их нельзя. Если правишь этот блок — сохрани
разделение, иначе получится гринвошинг.
